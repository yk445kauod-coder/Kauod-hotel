# V15 Feature Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the app every capability of `Kaoud-Invoice-WorldClass-V15.html` — same features, current look — on one clean invoice state machine.

**Architecture:** A single `status` column extended to `open → locked → printed` (+ `cancelled`), replacing V15's parallel `status`/`lock`/`print` fields. New endpoints add the print-confirm step, a lazy daily backup, owner-only clear-data, and a safe admin-password reset. The visual design and stack are unchanged.

**Tech Stack:** Cloudflare Workers (Hono) + D1, TypeScript, Zod (`@kaoud/core`), React/Vite web, vitest + Miniflare + esbuild tests.

**Spec:** `docs/superpowers/specs/2026-11-10-v15-parity-design.md`

## Global Constraints

- Status enum: `'draft' | 'open' | 'locked' | 'printed' | 'cancelled'` (exact strings).
- Keep the existing visual design, tabs, and component style — no V15 markup.
- Never introduce a hardcoded default password; never wipe `users`/`sessions`/`settings`/`tenants`.
- Financial invariants: cancelled rows are retained; serials are never reused.
- All new mutating routes that a client may replay are **online-only** (no outbox).
- Every commit ends with the trailer `Co-authored-by: openhands <openhands@all-hands.dev>`.

## Review Focus

- **Printing a `printed` invoice must succeed** (the whole point of the x-step) — pinned in Task 2.
- **`lock` must not move a `printed` invoice back to `locked`**, and `unlock` must not resurrect a `cancelled` one — pinned in Task 2.
- **ETA submission must still work after printing** (`locked | printed`) — pinned in Task 2.
- **Clear-data must re-seed `counters`**, or every create returns `counter_missing` — pinned in Task 6.
- **Clear-data must refuse a non-owner** and must keep users/settings — pinned in Task 6.

DROP TABLE invoices;

CREATE TABLE IF NOT EXISTS backups (
