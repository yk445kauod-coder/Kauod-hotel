# فندق قاعود سبورتنج — نظام الفواتير والضرائب

نظام فواتير متكامل لفندق قاعود سبورتنج، يعمل أونلاين وأوفلاين، مع فوترة إلكترونية
متوافقة مع منظومة الضرائب المصرية (ETA). يتكوّن من واجهة ويب (PWA)، وخدمة API،
وتطبيق سطح مكتب أصلي لويندوز يعمل بدون إنترنت.

## ⬇️ تحميل تطبيق الويندوز

| الملف | النظام | الحجم |
| --- | --- | --- |
| **[`kaoud-invoice.exe`](downloads/kaoud-invoice.exe)** | ويندوز 32-bit (يعمل أيضًا على 64-bit) | ~9.2 ميجابايت |

> اضغط على الرابط ثم على زر **Download** لتحميل التطبيق مباشرة من المستودع.
> التطبيق لا يحتاج تثبيتًا — شغّله مباشرة، ويعمل أوفلاين ويزامن تلقائيًا عند توفر الاتصال.

### التشغيل على أجهزة قديمة (Windows 7 / Intel Core Duo / 2 جيجا رام)

- النسخة **32-bit** هي المطلوبة للأجهزة القديمة وذات المعمارية 32-bit (مثل Intel Core Duo)،
  وهي تعمل أيضًا على أنظمة 64-bit — فنسخة واحدة تكفي لكل الأجهزة.
- التطبيق مبني بلغة Go كملف تنفيذي واحد بدون متطلبات تشغيل إضافية
  (لا .NET ولا Java)، واستهلاك الذاكرة منخفض ومناسب لـ 2 جيجا رام.
- إرشادات كاملة للأجهزة القديمة في [docs/legacy-windows.md](docs/legacy-windows.md).

## نظرة عامة

- **الويب (PWA):** https://kaoud-hotel.pages.dev — يعمل على الكمبيوتر والموبايل، ويدعم العمل أوفلاين عبر Service Worker.
- **الـ API:** https://kaoud-hotel-api.yk445kauod.workers.dev — خدمة Cloudflare Workers.
- **سطح المكتب:** تطبيق ويندوز أصلي (Go + walk) بقاعدة بيانات محلية، مصمّم للعمل الكامل بدون إنترنت.

### المزايا الرئيسية

- إنشاء وإدارة الفواتير مع بنود (إقامة / مطعم / ميني بار / مغسلة / إضافي).
- حساب الضريبة (VAT) والخصم تلقائيًا، وأسعار شاملة أو غير شاملة الضريبة.
- **بوابة الإرسال (Send gate):** لا يمكن إرسال فاتورة إجماليها غير صحيح — «سليمة» تمر،
  «تحتاج مراجعة» تتطلب تأكيدًا صريحًا، و«مرفوضة» لا يمكن إرسالها إطلاقًا.
- **الفوترة الإلكترونية (ETA):** إرسال الفواتير لمنظومة الضرائب المصرية.
- **العمل أوفلاين:** حجز أرقام فواتير مسبقًا، وطابور رفع (outbox) مع مزامنة تلقائية
  وحماية من فقدان البيانات عند تسجيل الخروج.
- **المدفوعات:** إنستاباي (InstaPay) حصرًا — بدون بوابات بطاقات.
- تقارير ورسوم بيانية، سجل نشاط، إدارة مستخدمين وصلاحيات (مالك / مدير / استقبال).
- تصدير Excel وطباعة A4 / طابعة حرارية.

## هيكل المستودع

```
apps/
  api/        خدمة Cloudflare Workers (Hono) + D1 (SQLite)
  web/        واجهة React + Vite (PWA)
  desktop/    تطبيق ويندوز الأصلي (Go + walk + bbolt)
packages/
  core/       منطق الحساب والمخططات المشتركة (Zod) — مصدر الحقيقة الواحد
downloads/    ملفات جاهزة للتحميل (kaoud-invoice.exe)
```

## التشغيل والتطوير

المتطلبات: Node.js 20+، وGo 1.20.x لبناء تطبيق سطح المكتب.

```bash
npm install                 # تثبيت الاعتماديات

npm run typecheck           # فحص الأنواع لكل الحزم
npm test                    # تشغيل كل الاختبارات (vitest)

npm run dev:api             # تشغيل الـ API محليًا (منفذ 8787)
npm run dev:web             # تشغيل الواجهة محليًا (منفذ 5173)
```

### بناء تطبيق الويندوز

```bash
cd apps/desktop
./build.sh                  # ينتج kaoud-invoice.exe داخل downloads/ وأيضًا dist/
```

### النشر

```bash
# المفاتيح تُقرأ من ملف .dev.vars في جذر المشروع
set -a && . ./.dev.vars && set +a

npm run deploy:api          # نشر خدمة الـ API
npm run deploy:web          # بناء ونشر الواجهة على Cloudflare Pages
```

## التقنيات

- **الواجهة:** React 18، Vite، Service Worker (PWA).
- **الـ API:** Cloudflare Workers، Hono، D1 (SQLite)، مصادقة بالرموز (Bearer).
- **المنطق المشترك:** TypeScript + Zod في `packages/core`.
- **سطح المكتب:** Go، مكتبة walk للواجهة، bbolt للتخزين المحلي.
